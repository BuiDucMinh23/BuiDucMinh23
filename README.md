# Xin chào, tôi là Bùi Đức Minh 👋

**Software Engineer** tập trung vào xây dựng các hệ thống nghiệp vụ web có khả năng mở rộng, dễ bảo trì và vận hành ổn định.

Hiện tôi làm việc chủ yếu với các bài toán quản trị nội bộ và cổng thông tin điện tử: quản lý nội dung, tài liệu, tệp, phân quyền, nhật ký hệ thống và API công khai cho người dùng cuối.

## Tôi đang làm gì

- Xây dựng và phát triển hệ thống quản lý văn bản quy phạm pháp luật cùng cổng thông tin điện tử.
- Thiết kế backend theo hướng phân lớp rõ ràng: API, Application, Domain và Infrastructure.
- Triển khai use case theo CQRS với Commands, Queries, DTO và MediatR.
- Phát triển giao diện quản trị và cổng thông tin công khai bằng React/Next.js.
- Tích hợp phân quyền, quản lý tệp/album ảnh, nhật ký hệ thống và theo dõi phiên đăng nhập.
- Build, migration và vận hành ứng dụng .NET trên IIS.

## Công nghệ chính

**Backend**

- C#, ASP.NET Core Web API, MediatR, Entity Framework Core
- Clean Architecture, CQRS, REST API
- SQL Server, migration và quản lý dữ liệu nghiệp vụ

**Frontend**

- React, Next.js, JavaScript
- Giao diện quản trị theo module, tái sử dụng component dùng chung
- Tích hợp API, phân quyền chức năng và trải nghiệm người dùng

**DevOps & công cụ**

- IIS, Git, npm, PowerShell
- Build, publish, kiểm thử API và xử lý sự cố triển khai
